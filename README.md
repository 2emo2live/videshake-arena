# VibeSnake

Оригинальный бот для [Battlesnake](https://play.battlesnake.com), ориентированный на режим **Duels** (1 на 1, standard rules).

## Как это работает

- **Движок**: своя симуляция хода по стандартным правилам (порядок операций: укорачивание хвостов,
  столкновения с телами с учётом освобождающихся хвостов, head-to-head, голод). Доска — битовые маски.
- **Поиск**: минимакс с альфа-бета отсечением по одновременным ходам обеих змеек,
  итеративное углубление под тайм-бюджет (~330 мс), реиграция лучшего хода с прошлой глубины.
  На 11×11 обычно достигается глубина 8–10 полуходов.
- **Эвристики**: контроль пространства (двойной BFS-флуд-филл), гонка за едой с учётом голода,
  избегание опасных голов соперника, мобильность, длина, здоровье. Веса — в `weights.json`.
- **Hill-climbing**: веса тюнятся автоматически — серия дуэлей «кандидат против чемпиона»,
  вариант принимается только если выигрывает больше, чем проигрывает (плюс маржа).

Весь код написан с нуля, открытые реализации змеек не копировались.

## Запуск

```bash
uv sync
uv run python -m vibesnake.api        # сервер на :8000 (PORT меняется переменной окружения)
```

Проверка:
```bash
curl localhost:8000/
curl -X POST localhost:8000/move -H 'Content-Type: application/json' -d @tests/sample_request.json
```

## Локальные дуэли и тюнинг

```bash
uv run run_local.py bench                    # бенчмарк времени хода
uv run run_local.py duel --n 16              # текущие веса против baseline-ботов
uv run run_local.py climb --iters 40        # hill-climbing весов (пишет weights.json)
```

## Переменные окружения

- `PORT` — порт сервера (по умолчанию 8000)
- `SNAKE_MOVE_BUDGET` — бюджет времени на ход в секундах (по умолчанию 0.33; лимит Battlesnake — 500 мс)
- `SNAKE_MAX_DEPTH` — максимальная глубина поиска (по умолчанию 6; фактически ограничена бюджетом)

## Docker

```bash
docker build -t vibesnake .

```
